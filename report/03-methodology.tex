\chapter{METHODOLOGY}

This chapter details the technical design and implementation of the proposed model, which introduces a new paradigm for Difference Visual Question Answering (DiffVQA) centered on efficiency, explicit reasoning, and robustness. The proposed methodology is a departure from the "brute-force," dense-processing approaches of prior work. Instead, we introduce a series of novel, lightweight modules designed to intelligently distill visual information, explicitly model the directionality of clinical change, and actively mitigate model hallucination. The architecture is designed to be self-contained, leveraging a self-supervised pre-training strategy to learn difference-sensitive representations without relying on external text corpora.

To ensure reproducibility, each component of the architecture is described in detail, from the initial feature extraction to the final loss calculation. The specific models, mathematical formulations, and training strategies will be comprehensively employed. The following sections will break down the three core stages of the methodology: the self-supervised warmup phase, the main VQA model architecture, and the final training strategy that combines generative and contrastive objectives. This modular design allows for clear, targeted evaluation of each of our core contributions. Figure~\ref{fig:high_architecture} shows high level architecture of the proposed methodology.

\section{Self-Supervised Pre-training: Masked Residual Modeling}
To equip the visual components of our model with a foundational understanding of radiological change, we employ a self-supervised pre-training strategy termed Masked Residual Modeling (MRM). This stage precedes the main VQA training and is crucial for our model's self-contained nature, as it learns difference-sensitive representations from images alone, without requiring radiology reports or other text corpora. Figure~\ref{fig:mrm} shows architecture of masked residual modeling module.

\subsection{Masked Residual Modeling}
The masked residual modeling (MRM) process is designed to force the model to learn the contextual structure of the difference maps. First, an unlabeled image pair $(I_{cur}, I_{ref})$ is passed through the Directional Residual Stack (DRS) to generate the concatenated residual map, $R$. A significant portion of the patches in this map, approximately 75 percent, are then randomly masked. The unmasked patches are fed into the QDT's vision backbone, which is tasked with predicting the content of the masked patches.

\subsection{Reconstruction Loss}
The training is guided by a reconstruction loss, which measures the dissimilarity between the model's predicted patches and the original, unmasked patches. We use a Mean Squared Error (MSE) loss for this objective.

$$
L_{\text{MRM}} = \frac{1}{|M|} \sum_{i \in M} (R_{i}^{*} - \hat{R}_{i}^{*})^{2}
$$

Here, M is the set of masked patch indices, $R_i$ is the original patch, and 
$\hat{R}_i$ is the reconstructed patch.

\section{Main Model Architecture}
Our main architecture is a novel, lightweight pipeline designed for efficiency and explicit reasoning. It comprises three key modules: the Directional Residual Stack (DRS), the Question-Guided Difference Tokenizer (QDT), and the Lightweight Answer Predictor.



\subsection{Directional Residual Stack}
To explicitly model the directionality of clinical change, the DRS computes three distinct residual maps from shallow features, f, extracted by a tiny, frozen backbone (e.g., a pre-trained ResNet-18).
\begin{itemize}
	\item Emergence/Worsening Map ($R^{+}$): This map isolates features that are new or more prominent in the current image.
	\[
	R^{+} = f(I_{\text{cur}}) - f(I_{\text{ref}})
	\]
	
	\item Resolution/Improvement Map ($R^{-}$): This map isolates features that have disappeared or become less prominent.
	\[
	R^{-} = f(I_{\text{ref}}) - f(I_{\text{cur}})
	\]
	
	\item Magnitude Map ($R_{\text{abs}}$): This map captures the overall, direction-agnostic magnitude of change.
	\[
	R_{\text{abs}} = |f(I_{\text{cur}}) - f(I_{\text{ref}})|
	\]
\end{itemize}

These three maps are then concatenated along the channel dimension to form a single, rich difference representation, $R$, which is passed to the next module.

\subsection{Question Guided Difference Tokenizer}
The QDT is designed to distill the dense $R$ map into a sparse set of the most relevant visual tokens. The natural-language question, q, is first encoded into a feature vector, $f_{Q}$, using a small, frozen text encoder such as ClinicalBERT's embedding layer. A single cross-attention layer then uses $f_{Q}$ as the query and the patches of $R$ as the keys and values. A Top-K selector with a Gumbel-Softmax is applied to the attention weights to select the K most relevant patches, which become our K Difference Tokens. This selection map is also preserved as an Evidence Heatmap for interpretability.

\subsection{Lightweight Answer Predictor}
To maintain computational efficiency, a small, frozen sequence-to-sequence language model such as T5-small is employed. Parameter-Efficient Fine-Tuning (PEFT) is used by adding trainable Low-Rank Adaptation (LoRA) adapters only to the cross-attention layers. The K Difference Tokens serve as the memory for these cross-attention layers, providing the necessary visual context for the language model to generate a free-form text answer.

\section{Training Strategy and Loss Functions}
The model is trained end-to-end using a dual-objective loss function designed to maximize both accuracy and robustness.

\subsection{Counterfactual Regularizer}
To mitigate the model's tendency to hallucinate, a counterfactual regularizer (CFA-Reg) is introduced. For each training sample $(I_{cur},I_{ref}, Q, A)$, we generate a logical opposite by either swapping the images $(I_{ref},I_{cur})$ or negating a directional term in the question (e.g., "worsened" → "improved"). The model performs a forward pass on both the real and counterfactual inputs, generating two distinct answer distributions, $P_{real}$ and $P_{cofa}$.

\subsection{Combined Loss Function}
The total loss is a weighted sum of a standard generation loss and the novel contrastive KL loss.
$$ L_{total} = L_{generation} + \dot{\alpha} $$

\begin{itemize}
	\item The Generation Loss $(L_{gen})$ is a standard cross-entropy loss between the model's predicted answer and the ground-truth answer for the real input.
	\item The Counterfactual Loss $(L_{CFA})$ is the negative Kullback-Leibler (KL) divergence between the real and counterfactual answer distributions. Minimizing this term forces the distributions apart, training the model to be sensitive to logical contradictions.
	\[
	L_{CFA} = -D_{KL}(P_{real}||P_{cofa})
	\]
\end{itemize}

\section{Dataset}
All experiments in this thesis will be conducted using \cite{medical-dff-vqa}. This dataset is the standard benchmark for the longitudinal chest x-ray Difference VQA task and was used by all related state-of-the-art models, ensuring a fair and direct comparison. The dataset contains 700,703 question-answer pairs over 164,324 pairs of longitudinal chest X-ray images.

The images are derived from \cite{mimic-cxr}. The JPG images used for training are sourced from \cite{mimic-cxr-jpg}, while the original DICOM files are sourced from \cite{mimic-cxr}. For the scope of this work, and in line with the focused approach of prior state-of-the-art research, only the "difference" question type subset will be used for training and evaluation.
